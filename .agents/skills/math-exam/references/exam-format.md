# 段考題目卷／答案卷版面規格

> 來源：`試卷範例.docx`（114 學年度第 1 學期第 3 次段考 數學科；校名已改空位符）。範例檔同目錄保留。
> `generate_exam_docx.py` 依此規格產出題目卷與答案卷。

---

## 紙張與邊界

| 項目 | 值 |
|------|-----|
| 紙張 | **B4 直式（25.7 × 36.4 cm）** |
| 左右邊界 | 1.5 cm |
| 上邊界 | 題目卷／學生答案卷3.5 cm；教師答案卷／題目卷審題版2.7 cm，預留跨欄卷頭 |
| 下邊界 | 1.5 cm |
| 頁首距離 | 0.7 cm |
| 頁尾距離 | 1.0 cm |

> ⚠️ 是 B4 不是 A4。段考卷題量大，B4 才排得下；用 A4 產出會爆頁。

---

## 字型

題目卷、學生答案卷、教師答案卷、題目卷審題版預設均為 **B4 直式、雙欄內文，欄距0.8 cm**。
卷頭放跨欄頁首，內文從同一頁直接接題；使用單一分節，不以連續分節造成只剩卷頭的空白首頁。
依左欄→右欄順序閱讀；各題及學生答案卷的作答空白盡量一起換欄。細目表及審題報告維持A4單欄。
未知數單字母（含普通文字中的 x、k）用 Cambria Math 斜體，數字和運算符用正體。
數字係數後接英文字母時省略乘號（17×x→17x）；數字乘數字與需要明示的運算保留乘號。

| 用途 | 字型 | 備註 |
|------|------|------|
| 題目與選項 | **標楷體** | 內文主字型 |
| 數學式 | **Cambria Math** | OMML 公式自動套用 |
| 配分說明行 | 新細明體，粗體 | 如「選擇25題，每題4分，共100分。」 |

---

## 卷頭（單格表格，置中）

用一個 1×1 的表格框住三行：

```
＿＿＿＿國中 {學年度} 學年度第 {學期} 學期第 {次別} 次段考 數學科 考試卷
{年級中文} 年 ___班　座號:___　姓名:______
範圍：{考試範圍}
```

範圍行可含配分權重，例如：`範圍：B5 1-1~3-1(20%)、B5 3-2(40%)、B6 1-1(40%)`

---

## 配分說明行

卷頭下方獨立一行，粗體：

```
選擇 {N} 題，每題 {X} 分，共 {總分} 分。
```

若各題配分不同，照 JSON 的 `mc_scoring` 原文輸出，例如
`1~7題每題4分、8~16題每題3分，共85分`。

---

## 選擇題

每題一段，格式：

```
（  ）題目文字……
(A) 選項一　(B) 選項二　(C) 選項三　(D) 選項四
```

排版規則：
- 題號前用全形括號 `（　）`，供學生填答；題號起點距欄左緣1.4cm，題幹起點2.0cm
- 選項以**全形空格**分隔
- 選項起點往右縮排，對齊題號（不對齊最左側作答括號）；長選項續行對齊選項文字。
- 雙欄每欄約10.95 cm，短選項每行兩個、長選項每個一行；選項標號起點1.4cm，單一長選項文字起點2.05cm
- 有配圖時，圖插在題目文字之後、選項之前，置中，寬度 5.5 cm

---

## 非選擇題

有填充題時，題目卷依序為「一、選擇題」「二、填充題」「三、計算題」。填充題每題只列題號、題幹與明確空格。
配分在區段標題統一說明，不逐題重複；不同分數也集中於區段說明。題幹跨行時用懸掛縮排，續行對齊第一行題幹文字，不能退回題號左緣。
填充題的題幹起點距欄左緣0.75cm，題號懸掛於左側；不要以手動空格模擬續行對齊。
未指定配置時為選擇 10×4、填充 10×4、計算 5×4（或指定 4×5），總分 100 分。
單一子題的計算題不重複顯示子題號與配分；多子題才逐一列出。

```
二、非選擇題（共 {總分} 分，須寫出計算過程）
{大題號}.（{總配分}分）題幹敘述……
　(1)（{配分}分）第一小題……

　(2)（{配分}分）第二小題……
```

- 區段標題用中文數字（一、選擇題／二、非選擇題）
- **大題號用阿拉伯數字**（1. 2. 3.），小題用 (1) (2)
  —— 大題號不要再用中文數字，否則會和區段標題的「二、」互相混淆
- 題目卷計算區只列題目；學生答案卷重列完整計算題並依序保留計算空間（目前約10行）。
- 不強制在題目卷的計算區前換頁，不在題目卷留大塊作答空白。
- 大題共用一圖時插在題幹後；小題各自有圖時插在該小題後

---

## 學生答案卷

選擇題與填充題均用空白表格供學生作答；每5題一組，第一列題號、第二列空白答案。
每組題號列與答案列必須一起換欄／換頁，以不可拆分的單列容器包住整組表格；只禁止各列拆分仍可能將兩列分開。
表格固定欄寬適應雙欄，填充題答案格高度須能容納手寫分數與代數式，不能預填正確答案。
計算題依序重列完整題目、必要配圖與作答空間，作答區與題幹一起換欄，不得包含答案或解析。

## 教師答案卷

只列答案：選擇／填充題用答案表格，計算題按題號列出答案。
每5題的題號列及答案列須作為同一區塊，空間不足時整組移至下一欄或下一頁，不得將題號與答案分開。
不重印題幹、不印解析、Bloom或給分說明。完整解析仍留在JSON作逐題驗算，輸出簡化不代表審查省略。

## 產出檔名

| 文件 | 檔名格式 |
|------|---------|
| 題目卷 | `{年級}數學第{次別}次段考_題目卷.docx` |
| 學生答案卷 | `{年級}數學第{次別}次段考_答案卷（學生版）.docx` |
| 教師答案卷 | `{年級}數學第{次別}次段考_答案卷（教師版）.docx` |
| 題目卷審題版 | `{年級}數學第{次別}次段考_題目卷（審題版）.docx` |
| 雙向細目表 | `{年級}數學第{次別}次段考_雙向細目表.docx` |
| 審題報告 | `{年級}數學第{次別}次段考_審題報告.docx` |

全部Word輸出到當次場次資料夾的 `Word/`；PDF放同場次 `PDF/`，版面渲染放 `驗收紀錄/`，結構見 [命題範本](exam-template.md)。獨立情境卷可填 `title` 取代場次檔名前綴，仍使用同一分卷規格。
題目卷審題版亦為B4直式雙欄，每題三部分及來源規範見 [審題版](question-review.md)。

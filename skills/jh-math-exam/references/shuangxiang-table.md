## 表二：細目分析（主表）

### 欄位結構（11 欄，表頭佔 2 列並做垂直合併）

```
第1列： 教材內容 │ 試題型式 │  記憶  │  了解  │  應用  │ 思考判斷（分析、綜合、評鑑） │ 合計(配分)
第2列： （合併）  │ （合併）  │配分│題數│配分│題數│配分│題數│    配分   │   題數      │ （合併）
```

| 欄序 | 內容 |
|------|------|
| 1 | 教材內容（節次名稱，跨 4 列合併） |
| 2 | 試題型式 |
| 3–4 | 記憶：配分、題數 |
| 5–6 | 了解：配分、題數 |
| 7–8 | 應用：配分、題數 |
| 9–10 | 思考判斷（分析、綜合、評鑑）：配分、題數 |
| 11 | 合計（配分） |

> ⚠️ 橫軸欄名用的是**「了解」與「思考判斷」**，不是「理解」與「分析」。
> 命題時內部一律用四級制（記憶/理解/應用/分析），匯出時自動對映，見 `bloom-taxonomy.md`。

### 列結構

每一個教材內容（節次）固定佔 **4 列**：

```
| 1-1 等差數列 | 選擇題      | … |
|  （合併）    | 填充題      | … |
|  （合併）    | 計算與證明題 | … |
|  （合併）    | 小計        | … |
```

- 空白表預留 5 個節次（20 列）＋ 最末 1 列「合計」＝ 23 列
- 實際產出時**依考試範圍的節次數量動態增減**，不必固定 5 個
- 「小計」列為該節次四種層次的加總
- 最末「合計」列為所有節次的總和，且「合計(配分)」欄應等於試卷總分

### 型式對映

| JSON 來源 | 填入「試題型式」 |
|----------|----------------|
| `mc_questions` | 選擇題 |
| `fill_questions` | 填充題 |
| `open_questions`（需寫過程） | 計算與證明題 |

`open_questions` 的計算子題一律計入**計算與證明題**列，`fill_questions` 計入填充題列；
若某節次某一型式沒有題目，該格留空（不要填 0）。

## 說明區（表格下方）

固定三行，字型與正文相同，前綴「【說明】」為粗體：

```
【說明】
請命題教師依照每一試題的認知層次，分類填入上表中。
試題型式請依照試卷編排順序填寫。
請計算各單元的小計與合計，並請計算配分總和。
```

---

## 填寫規則

1. **配分**欄填該節次該層次的總分，**題數**欄填題目數量
2. 空格代表該組合沒有題目，**留空不填 0**
3. 「小計」= 該節次四個層次配分加總
4. 「合計」列 = 各節次小計加總；最右「合計(配分)」欄必須等於試卷總分
5. 非選擇題以**小題**計入，不是以大題計入——一個大題兩小題分屬不同層次時，分別填在對應欄位

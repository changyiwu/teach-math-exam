# 段考命題預設範本

完整段考的預設入口；當次使用者明確指定的配置優先。教材、實際題目、來源審閱回覆及產出留在當次 `output/`，不存入技能原始碼。

## 預設配置

| 項目 | 預設 |
|---|---|
| 選擇題 | 10題，每題4分，共40分，四選一 |
| 填充題 | 10題，每題4分，共40分 |
| 計算題 | 5題，每題4分，共20分；可指定4題、每題5分 |
| 總分 | 100分 |
| 考試時間 | 未指定時先用45分鐘規劃並告知，可依教師需求調整 |
| 來源 | 按配分：使用者教材80%、公開網路資料或題庫20% |
| 文件 | 題目卷、學生答案卷、教師答案卷、題目卷審題版、雙向細目表 |
| 紙張 | 四種考卷B4直式雙欄；細目表A4單欄 |

版本、年級、學期、段考次別、範圍、學年度及教師資料依當次需求填寫，不能把示範卷資料當成已確認需求。
學校名稱未指定時，所有考卷與雙向細目表一律顯示「＿＿＿＿國中」；只有使用者提供校名時才填入 `school_name`，不可沿用範例校名。
只有範圍時可規劃；需要教材80%時須取得相應內容，未取得的課本或習作明列尚未核對。

## 全卷共同的命題規則

1. 讀取教材與習作，列出章內能力點、來源頁碼、已教解法及排除範圍，不能只列章節。
2. 先建立整卷「主重點×題型×認知層次」配分表，再決定每題來源。教材題與網路題合併規劃、合併驗收，不能各自配比後拼卷。
3. 各重點依教學比重配置，不強求每個小重點等分。每個作答單位只計入一個主重點，列出未獨立出題的能力，避免漏考或重複計分。
4. 來源80／20按配分計算，不是各章或各重點都各自80／20。25題各4分時對應20題教材、5題網路；24題配置須選出精確20分的網路題組合。
5. 兩類來源都重新設計數值與條件，不沿用課本、習作或網路原題的完整數值組合，不只更換姓名。不是禁止共用常見單一數字，而是避免完整原題換皮。
6. 逐題保留來源與改編方式：教材檔名／PDF頁碼，或網頁標題／網址／題號或段落／讀取日期。區分原題改編與參考能力點後原創，不虛稱每題均對應某道原題。
7. 網路題先提供完整題幹、選項、答案、解析、能力點、配分、來源及預計配置，取得使用者明確同意後才納入正式卷；改題後重新審閱。驗算或模型自審不能代替使用者同意。
8. 選擇題四選項有學習意義且唯一正解，不用「以上皆是／皆非」。A～D答案次數相差至多1題，不連續同答案。
9. 認知層次參考記憶10%、理解20%、應用40%、分析30%，按整卷配分檢查；偏離時如實標示，不把建議比例當成使用者已指定難度。
10. 網路題須符合 [官方課綱條文與備註限制](national-math-curriculum.md)，連同題幹、選項、解析及先備能力逐題核對當次範圍。另存 `curriculum_review.json`；有網路題的正式匯出必須提供 `--curriculum-report`，使用者同意不能取代課綱核對。

欄位與審閱摘要方法見 [來源與重點規劃](source-planning.md)，認知判定見 [Bloom準則](bloom-taxonomy.md)。

## 版面與四種考卷

共用：B4直式25.7×36.4cm、雙欄、欄距0.8cm，跨欄卷頭放頁首，標題下直接接內文。
用單一分節避免空白首頁，依左欄→右欄閱讀；依題量與作答空間排頁，不強制全部壓成一頁。
中文字型標楷體、內文12pt；未知數用Cambria Math斜體，包含普通文字及幾何標籤，公式用OMML。
數字係數接字母省略乘號（17×x→17x），數字乘數字保留；分數、根號、上標等正確排版。

| 文件 | 必須呈現 |
|---|---|
| 題目卷 | 卷頭後接題；選項縮排對齊題號，長選項續行對齊選項文字；填充題只在區段標題寫配分，續行對齊題幹；計算區列題目，作答空間放學生答案卷 |
| 學生答案卷 | 班級／座號／姓名；選擇與填充用空白答案表格，每5題一組；填充格可寫分數及代數式；計算題依序重列完整題目、配圖及計算空間，不得出現答案或解析 |
| 教師答案卷 | 只列答案：選擇／填充用答案表格，計算題依題號列答案；不印題幹、解析、Bloom或給分說明 |
| 題目卷審題版 | 每題三部分：本次完整題目；來源類型、精確頁碼題號或網址與原題；單元、主重點、Bloom及配分。能力點原創的教材對照須明示非直接改編來源 |
| 雙向細目表 | A4單欄，按節次、題型與認知層次統計實際題數及分數；不得拿來源分組代替整卷重點統計 |

精確邊界、縮排與檔名見 [版面規格](exam-format.md)。解析與給分依據仍保留在JSON中供驗算，不因教師卷只列答案而刪除。
學生／教師答案表每5題的題號列與答案列為一組，必須一起換欄或換頁，不能只禁止單列拆分。
幾何配圖依 `math-geometry` 技能及其唯一參數表產生，圖形條件、標籤與題幹一致，輸出前目視確認。

## 場次資料夾與空白資料範本

每份完整考卷集中在 `output/{學年度}-{學期}-{段考次別}-{年級數字}年級/`；年級數字1／2／3對應七／八／九年級。
命名採當次確認的資料，不能沿用示範卷場次；使用者另有指定名稱時優先。

```text
當次考卷/
├─ Word/            五份正式Word
├─ PDF/             五份正式PDF
├─ 命題資料/        exam_data.json、驗算及課綱報告、review_sources.json、重建程式
├─ 來源資料/        教材萃取、原題對照影像、配圖
├─ 驗收紀錄/        審閱紀錄、逐頁渲染、結構與版面檢查
├─ 歷史版本/        舊稿與更動前備份
├─ 檔案索引.md
└─ 整套考卷.zip
```

正式文件不與舊稿並列；重建程式必須讀當次命題資料並呼叫共用匯出器。舊稿保留供追溯，不作定稿入口。
跨場次研究與技能測試另放 `output/開發與研究/`，暫存放 `output/暫存/`，不混入正式壓縮檔。
移動資料夾後修正JSON以外的路徑設定、索引及腳本，驗證能從新位置重建；題目版本綁定的JSON不可只為整理路徑而任意改寫。

複製技能內 `assets/exam-template.json` 至當次考卷的 `命題資料/exam_data.json`，再填入主重點規劃、來源與實際題目。
此檔沒有假題目、假答案或預設同意紀錄；未填完時應被驗收器拒絕，不能直接當成考卷匯出。
計算題改成4題時，同時改 `expected_counts.open` 為4，並將每道計算題及子題合計調為5分。

```powershell
# $EXAM 指向當次考卷資料夾，建立方式見 SKILL.md Step 1。
$DATA = Join-Path $EXAM '命題資料'
New-Item -ItemType Directory -Force $DATA | Out-Null
Copy-Item (Join-Path $SKILL 'assets/exam-template.json') (Join-Path $DATA 'exam_data.json')
```

`$SKILL`、`$PY` 依SKILL.md取得；沿用共用匯出器，不另複製排版或數學邏輯。

## 交付前驗收

- 核對題數、題號、配分、全卷100分，主重點合計與規劃一致，兩類來源合計80／20。
- 核對課本與習作的完整數值條件；萃取異常時看影像，未讀內容不宣稱已核對。
- 逐題獨立重算答案、解析、選項唯一性及情境合理性；驗算報告與最終JSON摘要相符。
- 使用者同意綁定網路題最終版本；修改後不得沿用舊審閱或舊驗算報告。
- 網路題官方條文／備註及當次範圍／解法均通過核對；課綱報告須與目前題目和官方PDF版本一致，缺漏或不符不得匯出。
- 匯出五份文件，學生格不預填答案，教師卷不印解析，審題版三部分逐題齊全，配圖不缺漏。
- 實際渲染並逐頁看卷頭、選項及續行對齊、表格、公式、作答空間與換欄；不能只靠腳本成功就交付。

驗算指令、報告格式與限制見 [驗收流程](verification.md)。
審題版來源欄位與匯出參數見 [題目卷審題版](question-review.md)。

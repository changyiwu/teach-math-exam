# 考卷驗收與教材對照

## 結構檢查與數學驗算的界線

`scripts/exam_validation.py` 是兩個出題技能共用的檢查邏輯，匯出器會在建立任何 Word 前呼叫。

- 題號與計算子題號連續，無重複或缺號；題數符合 `expected_counts`（有提供時）。
- 各題配分為有限正數；選擇題的 `points` 與可解析的 `mc_scoring` 一致；不再以 0 分代替缺分。
- 計算大題分數等於子題分數合計；全卷分數等於最外層 `total_points`。
- 選擇題四個選項不空白且無文字重複，答案鍵有效；填充與計算題有答案、解析。
- 各題單元符合 `scope_sections`（有提供時），Bloom 層次可判讀；數學大括號成對。
- 新命題依 `source-planning.md` 提供主重點與來源規劃；合併教材題及網路題計算每個主重點，不能分開通過後才拼卷。
- 檢查全卷來源80／20及主重點目標配分同時成立；來源比例正確但合併後重點失衡仍報錯。網路題未審閱或內容已改動時禁止正式匯出。
- 提到「如圖」等字樣時有相對應圖形；正式匯出需要的 PNG 存在且可解碼。

答案平均分布與連續重複目前以警告提醒，命題者依 SKILL.md 的規則調整，不由程式自動換答案。
`--validate-only` 通過只表示結構正常；單元歸屬、題意、數學等價選項與證明完整性仍需實際解題審查。

## 本份考卷的驗算腳本

每份考卷在 `output/verify_math.py` 撰寫獨立驗算。可以使用標準函式庫的 `Fraction` 精確計算，
或已可用的代數工具。不要為所有題型假造一個「通用解題器」。

1. 讀取最終 `exam_data.json`，從題幹條件重建算式、方程式或限制。
2. 選擇題逐一檢查四個選項，必須恰好一個成立，且與 `answer` 對應；不能只驗答案字母。
3. 填充與計算題比較實際答案；根、分數與代數式應檢查等價性，不能只比浮點字串。
4. 逐步核對 `solution` 的等號、移項、單位及情境限制；不能只在解析中搜尋答案數字。
5. 任何不符立即 `raise` 或以非 0 結束；全部通過後才呼叫共用 helper 寫報告。

以下只展示報告介面，`checks` 必須在各題真正完成計算與斷言後逐一加入，**不可迴圈對每題直接填 True**：

```python
from exam_validation import write_math_report

# 例如：從該題條件重算，並驗證所有選項和解析後，加入此題紀錄。
checks.append({
    "id": "mc_1",
    "answer_verified": True,
    "solution_verified": True,
    "options_unique": True,
    "method": "由題幹獨立化簡，再逐一比較四選項與解析中的等價式"
})
# 所有作答單位完成後：
write_math_report(exam, checks, "output/math_check.json")
```

驗算腳本用絕對技能路徑加入 `sys.path`（先以 PowerShell `Join-Path` 組路徑），不要複製 helper。
報告 id 如下：

| 題型 | 驗算 id |
|---|---|
| 選擇題 | `mc_1` |
| 填充題 | `fill_1` |
| 計算子題 | `open_1_1` |
| 情境非選子題 | `q1_sub1`、`q1_sub2` |

報告含 `schema_version: 1`、整份考卷的 `exam_sha256` 與 `checks`。
它防止漏驗題目或沿用過期結果，不會自行證明腳本的數學推理正確。
一般匯出必須加 `--math-report output/math_check.json`；審題的 `--blueprint-only` 不要求補造答案或驗算。

## 教材對照與原創數值

在當次 `output/` 留下教材對照紀錄，包含來源檔名／PDF 頁碼、能力點、對應題號與排除範圍。
內建課綱不能冒充使用者提供的課本或習作；頁碼用 PDF 頁碼，若另有書頁碼再註明。

從能力點重新設計題幹、數值與情境。逐題核對以下項目：

- 概念與解法在本次範圍內，不因套用幾何題就混入尚未教的畢氏定理等單元。
- 不沿用課本或習作原題的完整係數、常數、金額或長度組合；常見單一數字或固定定義中的數字不視為複製原題。
- 不把換名字、改選項順序當作新題；數值修改後重新驗算，檢查是否仍有唯一解及合理答案。
- 文字萃取有亂碼或公式不全時看原頁影像，不以文字搜尋無命中宣稱已排除重複。
- 未取得的教材或未完成的比對明確標記待核對；來源教材不放進公開 repo。

## 最後檢查

題目卷、答案卷、雙向細目表皆須轉成頁面圖檢查：題幹與選項不可拆散、計算留白足夠、公式與題圖完整，
細目表總分與題數須再對照驗算摘要。不要用「檔案已產生」代替版面驗收。
